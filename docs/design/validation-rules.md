# 스키마 값 검증 규칙

일반 테이블의 `*.schema.xlsx`에 선택 열 E(`Rule` 또는 `규칙`)를 둔다. 기존 A~D 열과 자료형 문법은 유지한다. 열이 없거나 규칙이 빈 경우 기존 출력과 스키마 해시는 그대로 유지한다. `drtable new`는 기존 스키마를 읽어 데이터 파일만 생성하므로 스키마 생성 명령을 추가하지 않는다.

규칙은 세미콜론으로 구분한다. `필수`/`required`는 기본값 적용 전의 빈 데이터 셀을 거부한다. 숫자형은 `0..100`(양 끝 포함), `>=0`, `<1000`을 지원한다. 문자열형은 `len<=32`(Unicode 문자 수)와 `regex:^[A-Z_]+$`을 지원한다. 규칙은 해당 자료형에만 허용한다. 배열은 빈 배열에 필수를 적용하고 각 원소에 나머지 규칙을 적용한다. `fixed<N>`의 범위는 저장된 정수가 아닌 엑셀에 적은 소수 값으로 검사한다. 선언된 기본값도 검사한다.

규칙 문법·자료형 오류와 기본값 오류는 스키마 E셀을 가리킨다. 데이터 오류는 실제 데이터 셀을 가리키며 한국어·영어 메시지를 제공한다. 규칙이 있는 필드에만 규칙 텍스트를 스키마 해시에 넣어 규칙 변경을 감지한다. 생성 C++의 형식은 변경하지 않는다.
